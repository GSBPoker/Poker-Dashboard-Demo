What this is
This dashboard tracks two years of professional poker play: every session, venue, stake, and result. I built it end to end with Claude Code and GitHub — data pipeline, charts, filtering, and the bankroll and AI-analysis features below.

The data on this page is synthetic. It's shaped to match the real structure and scale of my actual session log, but the numbers are generated, not my real results.
How to read each tab
Overview
Headline numbers — total profit, hourly rate, win rate — plus cumulative profit over time and a month-by-month breakdown of the last year.
Venues
Performance broken out by room: profit, hourly rate, and win rate per venue, with a full sortable table.
Geography
The same breakdown by market instead of venue — Las Vegas, New York, Atlantic City, and so on.
Stakes
Performance by stake level, plus the single biggest win and loss recorded at each stake.
Sessions
The full session log — every row in the dataset, sortable, with best and worst sessions called out separately.
Bankroll
A bankroll tracker layered on top of the session data. It starts from a set amount on a set date, adds or subtracts each session's result automatically, and lets me route winnings toward specific savings goals — with a running log of what went where.
AI Insights
A concept for pattern detection and bankroll analysis powered by the Claude API — pattern spotting, bankroll health checks, and open-ended Q&A over the session data. In this demo the buttons are wired up but not connected to a live model, so clicking one shows a short notice instead of running a real analysis.
